---
title: Метеостанция по сети
---

Задание: написать программу, которая будет отправлять температуру числом в топик **"smena/X/temperature"**, а относительную влажность в топик **"smena/X/humidity"** раз в 3 секунды *(для таймера не использовать delay()!).*

Отправка сообщений в топик выполняется командой:

```arduino
client.publish(топик_куда_отправляем, что_отправляем);
```

Отправку выполнять в цикле loop();

Важно: отправлять с помощью функции publish можно сообщения типа c_str. Влажность и температура у нас изначально - это числа, причем нецелые (тип float). Поэтому нужно выполнить преобразование float -> c_str (подробно про строки разницу между их типами еще раз: [String-строки](https://alexgyver.ru/lessons/strings/), [Си-строки](https://alexgyver.ru/lessons/cstring/)). Напрямую такое преобразование сделать не получится: сначала нужно преобразовать число float в String, а затем из String в c_str.

Для этого создайте в начале кода вместе с переменными float temp; float hum; также переменные для значений температуры и влажности, но строками ("текстом"): String temp_string и String hum_string.

Далее, там же в коде, где вы выполняете получение данных с датчика:

```arduino
temp = dht_sensor.readTemperature();
hum = dht_sensor.readHumidity();
```

добавьте преобразование в String и запись в новые переменные:

```arduino
temp = dht_sensor.readTemperature();
hum = dht_sensor.readHumidity();

temp_string = (String)temp;
hum_string = (String)hum;
```

(конечно, при желании можно это сделать без лишних переменных одной строкой, если хотите - попробуйте самостоятельно)

Там, где вы будете отправлять данные командой client.publish() выполните преобразование String->c_str:

```arduino
client.publish(название_топика, temp_string.c_str());
```

(для влажности аналогично)

<summary>

Подсказки

</summary>

-  **не забудьте создать топики в самом начале**
-  функция setup_wifi() отвечает за подключение к WiFi -она не интересует нас;
-  функция callback() отвечает за реакцию на пришедшие сообщения, а мы должны отправлять сообщения, то есть тоже не подходит.
-  Функция reconnect() отвечает за подключение к MQTT, тоже не то. Но в ней можно найти пример, как опубликовать сообщение
-  функция setup() выполняется 1 раз при запуске, не то
-  функция loop() выполняется постоянно по кругу. Можно попробовать добавить публикацию сообщений в ней
-  **Но не забудьте про таймер!**

</details>

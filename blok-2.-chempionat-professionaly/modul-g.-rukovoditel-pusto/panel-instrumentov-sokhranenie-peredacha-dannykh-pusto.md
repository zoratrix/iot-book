# Панель инструментов (сохранение, передача данных) (пусто)

На панели инструментов нужно разместить два переключателя: "передавать данные"  и "сохранять данные". Глобальные переменные для этих переключателей такие же, как на дашборде оператора (передавать данные) и на обоих предыдущих дашбордах (сохранять данные):

<figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

Код "передавать данные"

```javascript
global.set("controlSwitch", msg.payload)
return msg;
```

Код "сохранять данные":

```javascript
global.set("saveSwitch", msg.payload)
return msg;
```
